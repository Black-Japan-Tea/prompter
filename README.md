# Prompter — суфлёр для Markdown

Окно-подсказка для видеосозвонов: висит поверх всех окон, читается только вами
и **не попадает в трансляцию экрана** (Zoom, Teams, Discord, Google Meet, OBS,
скриншоты). Запускается в трее (двойной клик — показать окно, ПКМ — меню), кнопки на панели задач не занимает. Кнопки ☰/–/✕ в шапке всегда видимы; ✕ и – прячут окно в трей, приложение продолжает работать. Esc ничего не прячет — только закрывает меню.

## Как это работает

Приложение вызывает Win32 API `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` —
окно исключается из всех системных каналов захвата экрана, но на физическом
мониторе отображается как обычно. Требуется Windows 10 версии 2004+.

## Управление

Всё доступно тремя способами: **меню в окне** (кнопка ☰ слева в шапке, `F10`,
клавиатурная навигация стрелками), **меню трея** и **горячими клавишами**.

| Функция | Хоткей (глобальный) | Дополнительно в окне |
|---|---|---|
| Показать / скрыть окно | `Ctrl+Alt+P` — единственная комбинация-тогл | кнопки – и ✕ в шапке |
| Показать окно | — | двойной клик ЛКМ по иконке трея |
| Открыть файл… | `Ctrl+Alt+O` | `Ctrl+O` |
| Открыть недавний | `Ctrl+Alt+R` | пункты «Недавние» в меню |
| Последний файл | `Ctrl+Alt+Enter` | пункт меню |
| Прозрачность + / − (0% — непрозрачно, до 95% — почти невидимо) | `Ctrl+Alt+=` / `Ctrl+Alt+-` | пункты меню |
| Автопрокрутка вкл/выкл | `Ctrl+Alt+Space` | чекбокс в меню |
| Скорость: медленно / средне / быстро | `Ctrl+Alt+1/2/3` | радио в меню |
| Невидимость в трансляции | `Ctrl+Alt+V` | чекбокс в меню; выключение = окно видно участникам |
| Клик-сквозь | `Ctrl+Alt+T` | чекбокс в меню |
| Поверх всех окон | `Ctrl+Alt+A` | чекбокс в меню |
| Выход | `Ctrl+Alt+Q` | `Ctrl+Q` |
| Размер шрифта 12–28px | — | `Ctrl+=/-`, `Ctrl+колесо` |
| Меню приложения | — | `F10`, кнопка ☰ |

**Фолбэки хоткеев.** Если комбинация занята другой программой (Win32
`RegisterHotKey` отказывает индивидуально, зависит от машины), приложение
автоматически пробует запасные (`Alt+Shift+…`, `Ctrl+Shift+…`) и показывает
тост с реально работающими комбинациями. Меню всегда отображает актуальные
хоткеи.

Скроллбар скрыт: у правого края — единая фиолетовая полоса-позиция (10px); при наведении в зоне она оживает и перетаскивается. Каждое действие сопровождается тостом-фидбеком (прозрачность, скорость,
клик-сквозь, ошибки открытия файла). Правки открытого файла подхватываются
на лету (debounce 150 мс). Настройки переживают перезапуск, повторный запуск
показывает уже открытое окно (single-instance).

## Сборка и разработка

Требуется Node.js 22+. При сетевых сбоях npm используйте зеркало:
`--registry=https://registry.npmmirror.com`, `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/`,
`ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/`.

```bash
npm install            # зависимости (все dev — рантайм-зависимостей нет)
npm run icons          # перегенерировать иконки (PNG/ICO, без внешних библиотек)
npm test               # юнит-тесты (vitest, TDD Red-Green-Refactor, 88 тестов)
npm run test:e2e       # E2E: 45 тестов — базовые сценарии, меню, хоткеи,
                       # комбинаторика всех пар действий (16×16)
npm run typecheck      # строгий tsc для main+preload и renderer
npm start              # dev-запуск
npm run dist           # сборка: release/Prompter-Setup-<v>.exe (NSIS) и Prompter-Portable-<v>.exe
```

Smoke-тест собранного бинарника:
`PACKAGED_EXE="<путь к exe>" npx playwright test tests/e2e/packaged.spec.ts`

Тихая установка/удаление (Git Bash: флаги `/S` портятся MSYS — запускайте через cmd):

```bash
cmd //c "release\\Prompter-Setup-1.2.0.exe /S /D=C:\\путь\\без\\пробелов"
powershell -Command "Start-Process -FilePath 'C:\\путь\\Uninstall Prompter.exe' -ArgumentList '/currentuser','/S' -Wait"
```

## Архитектура

- `src/main` — main-процесс: окно (`setContentProtection`, `skipTaskbar`,
  frameless, always-on-top), трей, глобальные хоткеи с фолбэками,
  `DocumentController` (файлы, watcher, недавние), `IpcBridge` (валидация
  недоверенных payload), `SettingsStore` (JSON, атомарная запись), single-instance.
- `src/preload` — contextBridge API (contextIsolation + sandbox, бандлится
  esbuild: sandbox-preload не умеет локальные require).
- `src/renderer` — тема «Графит + индиго», безопасный рендер Markdown
  (markdown-it + DOMPurify), автопрокрутка на rAF, меню с ARIA-ролями и
  клавиатурной навигацией, тосты, drag&drop через `webUtils.getPathForFile`.
- `src/shared` — типы настроек, реестр команд и акселераторов (единый
  источник для main, renderer, меню и трея).
- `src/tools` — генератор иконок: собственный PNG-энкодер (zlib + CRC32),
  пиксельный художник (SDF-антиалиасинг) и сборщик Windows ICO.
- `tests/unit` — 88 юнит-тестов (реальные файлы и fs.watch, без моков);
  `tests/e2e` — 45+1: 9 базовых сценариев, 9 меню (клики, клавиатура,
  ARIA, состояния), 11 хоткеев (регистрация, фолбэки, реальные нажатия),
  16×16 комбинаторика пар действий с инвариантами после каждого шага.
